## 📝 Overview

**Realtime-Tracker** is a web application that provides a real-time device tracking solution. Built using **Node.js**, **Express**, **EJS**, **Socket.IO**, and **Leaflet**, it allows users to monitor the live location of devices on a map interface. Each connected device's position is dynamically updated as they move, offering a sleek and interactive user experience.

---

## 🚀 Features

- 📡 **Live Location Tracking**: Monitor devices in real-time on an interactive map.
- 🗺️ **Dynamic Map Interface**: Utilizes Leaflet.js for responsive and customizable mapping.
